## 📸 About the Project
A practical daily task manager that lets you add tasks with due dates, track your to-dos, and keep your data saved even after closing the browser. Built as a hands-on JavaScript project to practice DOM manipulation and browser storage.

## ✨ Features
- ➕ Add tasks with a title and due date
- 📅 Date picker for setting task deadlines
- 💾 **localStorage** — tasks are saved and persist after page refresh or browser close
- 🗑️ Delete tasks you no longer need

## 🛠️ Technologies Used
| Technology | Purpose |
|---|---|
| HTML5 | App structure and form elements |
| CSS3 | Styling and layout |
| JavaScript (ES6) | Task logic, DOM manipulation, localStorage |

## 🧠 How It Works
1. User types a task name and selects a due date
2. Clicking "Add" creates a new task card on the page
3. Tasks are saved to `localStorage` as a JSON array
4. On page reload, tasks are loaded back from `localStorage`
5. Users can mark tasks done or delete them

## 🚀 How to Run Locally
1. Clone the repository:
   ```bash
   git clone https://github.com/karshu454545-dev/To-Do-List.git
   ```
2. Open `index.html` in your browser.
